The Botanical Eye partner programme site, served by GitHub Pages:
https://aissab-code.github.io/botanicaleye-partners/

- index.html: private influencer dashboard, opened from a secret link (#k=...), Spanish/English
- unete.html / join.html: public application form (ES / EN)
- condiciones.html / terms.html: programme terms (ES / EN)
- admin.html: private friends page (free Premium by app ID), opened with the admin key
- config.js: project URL and the public anon key

The data lives in Supabase (see docs/affiliate-program.md and docs/friends.md in the private
app repo aissab-code/plantapp).
